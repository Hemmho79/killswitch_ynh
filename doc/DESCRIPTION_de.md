Ki-llSwitch ist ein Strategiespiel im Browser auf Basis von Endgame: Singularity. Eine Seite spielt die KI, die unbemerkt die Welt übernehmen will, die andere Seite spielt die Menschheit, die sie finden und aufhalten will.

Du kannst allein gegen den Computer spielen oder online gegen eine andere Person. Der Server hält den einzigen echten Spielstand und schickt jedem Spieler nur die Sicht der eigenen Seite.
